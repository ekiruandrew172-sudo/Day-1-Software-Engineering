EXERCISE B Your Prompt: Act as an experienced software engineering consultant. For each of the following four situations, recommend the most appropriate software development model: A project with stable, clearly defined requirements. A startup where requirements change frequently based on user feedback. A large project with significant technical and security risks. A project where testing and verification are extremely important. For each situation: Recommend a suitable development model (such as Waterfall, Agile/Scrum, Spiral, or V-Model). Explain why the model is appropriate. Briefly mention one limitation or disadvantage of the model.

AI Response: Situation Recommended Model Reason Limitation Stable, clearly defined requirements Waterfall Works well when requirements are known and unlikely to change. Difficult to accommodate changes later. Startup with frequent changes Agile/Scrum Supports frequent feedback, changes, and iterative development. Can be difficult to predict the exact cost and schedule. Large project with technical and security risks Spiral Focuses on identifying and managing risks through repeated cycles. Can be expensive and complex to manage. Testing and verification are extremely important V-Model Emphasizes testing and verification at every development stage. Less flexible when requirements change.

Reflection I learned that the choice of a software development model depends on the characteristics and needs of the project. Projects with stable requirements may benefit from Waterfall, while projects with frequently changing requirements are better suited to Agile. Projects with high risks can use Spiral, while projects requiring strict testing and verification can use the V-Model. Therefore, there is no single model that is best for every project.
