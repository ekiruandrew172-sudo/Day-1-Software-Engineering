EXERCISE A
Prompt 1: Zero-Shot
Your prompt:
Explain the Software Development Life Cycle (SDLC). Describe its main phases and why each phase is important.
AI response:
The Software Development Life Cycle (SDLC) is a structured process used to develop, test, deploy, and maintain software. Its main phases are Planning, Requirements Analysis, System Design, Implementation/Coding, Testing, Deployment, and Maintenance. Each phase helps ensure that the software meets user requirements, works correctly, and can be maintained over time. Following the SDLC provides a systematic approach that improves software quality and reduces development risks.
3–5 sentence summary:
The SDLC provides a systematic process for developing software. It includes planning, requirements analysis, design, coding, testing, deployment, and maintenance. Each phase has a specific purpose and contributes to the quality of the final software. Using the SDLC helps teams develop reliable and maintainable software.
Prompt 2: Role Prompting
Your prompt:
Act as an experienced software engineering instructor. Explain the Software Development Life Cycle (SDLC) to a group of beginner computer science students. Use simple language and give a short description of each SDLC phase. Present your answer using headings and bullet points.
AI response:
The Software Development Life Cycle (SDLC) is a step-by-step process used to develop and maintain software.
1. Planning: Identify the project goals, resources, time, and costs.
2. Requirements Analysis: Determine what users need the software to do.
3. System Design: Create the structure and design of the software.
4. Implementation: Developers write the actual program code.
5. Testing: The software is tested to find and fix errors.
6. Deployment: The completed software is released for users.
7. Maintenance: The software is updated, improved, and fixed after release.
3–5 sentence summary:
The SDLC is a structured process for developing software from an initial idea to a finished product. It consists of several phases, including planning, requirements analysis, design, implementation, testing, deployment, and maintenance. Each phase has a specific purpose and helps improve software quality. Following the SDLC helps developers create reliable software that meets users' needs.
Compare – Which response was more useful?
The Role Prompting response was more useful because it clearly specifies the audience, role, and format. The AI uses simpler language that is easier for beginner students to understand and organizes the information with headings and bullet points. The Zero-Shot response was useful, but the Role Prompting response gives more structured and audience-specific information.

Reflection
I learned that the choice of a software development model depends on the characteristics and needs of the project. Projects with stable requirements may benefit from Waterfall, while projects with frequently changing requirements are better suited to Agile.
